# personal-leak-audit
Учебная утилита на Python для проверки паролей и email через Have I Been Pwned, проверки TCP-портов localhost, просмотра истории и экспорта отчетов.
# Персональный сканер утечек и базового аудита безопасности

Небольшая учебная программа на Python: проверяет пароль через API Have I Been
Pwned с использованием k-Anonymity, ищет утечки email, проверяет TCP-порты
локального компьютера и сохраняет историю проверок.

## Требования

- Python 3.10 или новее.
- Интернет для проверок через Have I Been Pwned.
- Для проверки email нужен API-ключ HIBP. Получите его на официальном сайте
  [Have I Been Pwned](https://haveibeenpwned.com/API/v3) и следуйте актуальным
  условиям и инструкциям сервиса.
- Для графического окна нужна поддержка Tkinter в установленном Python.
  Если Tkinter недоступен, используйте консольное меню.

Дополнительные Python-пакеты не нужны: программа использует стандартную
библиотеку.

## Запуск в Windows

1. Откройте PowerShell и перейдите в папку со скриптом:

   ```powershell
   cd C:\password
   ```

2. Запустите консольную программу:

   ```powershell
   python .\leak_audit.py
   ```

   Если команда `python` не найдена, попробуйте команду Windows Launcher:

   ```powershell
   py -3 .\leak_audit.py
   ```

3. Выберите действие, введя номер пункта меню. Для выхода выберите `0`.

### Проверка email

В той же сессии PowerShell задайте ключ HIBP, а затем запустите программу:

```powershell
$env:HIBP_API_KEY = "ваш-api-ключ"
python .\leak_audit.py
```

Переменная таким способом действует только в текущем окне PowerShell.
Проверка email попросит подтвердить отправку адреса сервису HIBP. API-ключ
не записывается в историю. Не публикуйте его и не добавляйте в исходный код.

## Пункты меню

- **1 — Проверить пароль.** Ввод скрыт. Скрипт отправляет HIBP только первые
  пять символов SHA-1-хэша; полный хэш сверяется локально. Пароль и его хэш
  не записываются в историю.
- **2 — Проверить email.** Требуются интернет и переменная `HIBP_API_KEY`.
  Адрес отправляется HIBP только после подтверждения. В локальной истории
  адрес маскируется.
- **3 — Сканировать локальные порты.** Проверяются TCP-порты на `127.0.0.1`.
- **4 — Открыть графический интерфейс.** Проверку можно выбрать из списка;
  в окне также есть кнопки сохранения отчета, просмотра истории и настройки
  портов.
- **5 — Показать историю.** Выводит последние проверки.
- **6 — Настроить список портов.** Введите номера через запятую, например
  `22,80,443,8080`.
- **7 — Сохранить последний отчет.** Введите путь к текстовому файлу,
  например `C:\Users\Имя\Desktop\audit.txt`.
- **0 — Выход.**

## Файлы данных

При настройке портов или сохранении истории программа создаст рядом со
скриптом:

- `leak_audit_config.json` — настроенные номера TCP-портов и их подписи.
- `audit_history.json` — история проверок. В нее не попадают пароль,
  хэш пароля или API-ключ; email в сохраненных отчетах замаскирован.

Отчеты, экспортированные вручную, сохраняются по выбранному вами пути.
При необходимости удалите эти файлы вручную, чтобы очистить историю или
конфигурацию.

## Важно

Это учебная утилита, а не полноценный аудит безопасности. Отсутствие
совпадений в HIBP не гарантирует, что пароль или email никогда не попадали
в утечки. Открытый порт на `127.0.0.1` сам по себе не означает, что служба
доступна из интернета. Проверяйте только собственный компьютер.
